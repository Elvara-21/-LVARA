# ÉLVARA — Fashion Storefront

A responsive premium womenswear brand concept built with React, Vite and Three.js.

## Features
- Editorial cream / beige / black visual identity
- Responsive navigation and mobile menu
- Collection filters and product search
- Product quick-view modal
- Demo shopping bag with quantity controls and subtotal
- Interactive Three.js 3D fashion-inspired sculpture (pointer-responsive)
- Journal / social post preview section
- Coming-soon email form (front-end demo only)
- Responsive desktop, tablet and mobile layouts

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite (usually http://localhost:5173).

## Build
Run `npm run build`. The production site is created in `dist/`.

## Important launch notes
This is a polished front-end storefront prototype. Product names, prices and imagery are sample/demo content. The bag is client-side only and does not process orders or payments. The coming-soon form displays a local success state but does not store or email addresses. Before accepting real orders, replace demo product data and images, connect a secure backend, email-list provider and compliant payment/checkout provider, and publish accurate shipping, return, privacy and contact policies. Since the founder is under 18, a parent/guardian should supervise business registration, supplier agreements and payment accounts.
